# Mục 8 — Appendix

Giai đoạn 2, Lượt 4. Điền Appendix trống bằng các tiểu mục/bảng dưới đây. Các giá trị trong [ ] vẫn là đề xuất; không tự bổ sung ngôn ngữ, category, ngưỡng hoặc kế hoạch triển khai. Mỗi dòng bảng thay đổi dưới đây cung cấp đoạn tiếng Anh dán được; khi tạo bảng con, tách các nhãn thành cột tương ứng. Không thay nội dung PRD cũ bằng glossary.
